## 第 1 步：改小程序名称（先做，名称审核要时间）

1. mp 后台左侧 **首页**（或 **设置**）→ **基本信息**
2. 找到 **「小程序名称」** 那一行 → 点右侧 **「修改」**
3. 输入新名称，建议（品牌名，不带描述句）：
   - `徕舞普拉提`
   - `徕舞普拉提工作室`
   - `徕舞 Pilates`
   - 注意：避开「会员 / 系统 / 陪伴 / 成长 / 约课」这类通用词，否则继续被判通用词
4. 提交 → 等审核（一般几小时到 1 天）→ 通过后再做第 2 步

> 当前名称「徕舞会员成长陪伴系统」审核不通过，还剩 2 次修改机会，别乱试。
> 主体是个人，「服务类目：工具 > 健康管理」保持不变即可，不需要支付资质。

## 第 2 步：把 1.3.2 设为体验版

1. mp 后台左侧 **管理 → 版本管理**
2. 页面切到 **「开发版本」** 标签页
3. 找到版本号 **`1.3.2`**（描述：无卡会员可看课表但不能预约（1.3.2），118.9KB）
4. 点右侧 **「设为体验版」** → 出现 **体验版二维码**
5. 手机微信扫码（管理员本人可直接扫；其他人要先加：**管理 → 成员管理 → 体验成员 → 添加**）
6. 手机上依次点：
   - 「预约」→ 顶部应出现「还没有有效会员卡…」提示条（无卡会员）
   - 用有卡会员登录（如 秦卓宇 邀请码 `A1132370` / 手机尾号 `190494`）→ 能约课、能看到「我的卡 余 10/10」
   - 我的蜕变 → 显示「秦卓宇 先生/女士」和「第 N 天」，不报错

## 第 3 步：提交审核

1. **管理 → 版本管理 → 开发版本** → 对 `1.3.2` 点 **「提交审核」**
2. 按提示填写：
   - **功能页面**：选「预约」或首页
   - **版本描述**：`门店会员约课与课时记录；需门店开卡后预约`
   - **测试账号**（重要，审核员要用）：
     - 会员端登录方式：邀请码 + 手机尾号
     - 测试会员：邀请码 `A1132370`，手机尾号 `190494`
   - 类目：`工具 > 健康管理`（保持现状）
3. 提交，等审核（一般 1–3 个工作日）
