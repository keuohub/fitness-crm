## 二、部署前必须准备

1. 腾讯云托管控制台权限（或明确授权我操作）。
2. 确认生产环境变量：
   - 必填：`DATABASE_URL`、`ADMIN_PASSWORD`、`MEMBER_TOKEN_SECRET`
   - 微信：`WECHAT_APPID`、`WECHAT_APPSECRET`
   - 订阅消息：`WX_TEMPLATE_BOOKING_SUCCESS`、`WX_TEMPLATE_CLASS_REMINDER`、`WX_TEMPLATE_CANCEL`、`WX_TEMPLATE_NOTE`
   - 可选：`COACH_TOKEN_SECRET`、`COOKIE_SIGN_KEY`
3. 修改管理员密码为强密码。
4. 小程序合法域名 / 云托管 callContainer 指向新服务。
5. 备份数据库（见下）。

## 三、数据库

本次 S6 **没有新增迁移**；复用 S1–S5 迁移：

```bash
node scripts/migrate-booking-schema.mjs
node scripts/migrate-s2-cards.mjs
node scripts/migrate-s3-schedule.mjs
node scripts/migrate-s3-templates.mjs
node scripts/migrate-s4-bookings.mjs
```

迁移脚本均为幂等 `CREATE/ALTER IF NOT EXISTS`，不会删数据。生产执行前仍需备份。

备份建议：
- Neon 控制台建 branch / PITR 快照；
- 或 `pg_dump` 导出（连接串不写入仓库/日志）。

恢复演练：在 Neon branch 上恢复一次，验证核心表行数，再决定是否用于生产。
