## 一、会员数据录入

### 必填字段

| 字段 | 来源 | 示例 |
|------|------|------|
| name | 会员真实姓名 | 王莉 |
| phone | 会员手机号（用于 Portal 登录） | 138xxxx |
| gender | 固定 female | female |
| stage | 会员阶段 | active |
| joinedAt | 入会日期 | 2025-04-01 |
| portalEnabled | 1（开启 Portal 访问） | 1 |
| portalCode | 6位数字邀请码 | 123456 |

### 录入方式

```
方式 A：Admin 后台手动录入（http://localhost:3001/members/new）
方式 B：种子脚本批量导入
```

### 隐私红线
- 会员真实手机号仅在 CRM 后台可见
- Portal 默认不展示手机号
- 案例展示使用「李女士」「张女士」等匿名

## 三、案例录入规范

### 案例标准
- 至少 10 次以上训练记录
- 至少有 1 次以上体态照片
- 至少有 1 份阶段报告

### 展示格式
```
姓名（匿名：李女士）
职业
训练次数
坚持月数
一句真实记录
```

## 四、续课率统计

### 定义
续课率 = 本期到期后续课的会员数 / 本期到期会员总数 × 100%

### 当前展示数据
- 88.7%（品牌层级宣传数据）
- 真实统计口径待第一次运营周期后确认
