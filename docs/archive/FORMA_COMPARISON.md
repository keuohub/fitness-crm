# FORMA_COMPARISON.md

> 徕舞 vs Forma Pilates 首页对标分析
> 分析时间：2026-06-04

---

## 一、板块数量

| | Forma | 徕舞 |
|------|:---:|:---:|
| 首页板块数 | ~7 | 17 |
| Hero 信息层 | 1 层（大标题） | 3 层（品牌名+标题+副标题） |
| CTA 数量 | 1 个主 CTA | 15+ 链接/按钮 |
| 产品/功能介绍 | 0 | 5 个（Ecosystem/HowItWorks/AIReport/Partner/Try） |

## 二、关键差距

### 差距 1：板块数量过多
- Forma: 7 个板块，每个板块之间有充足留白
- 徕舞: 17 个板块，下半段连续 7 个板块是功能说明
- **影响：** 用户滚到一半就开始疲劳

### 差距 2：无 revenue proof 在前半段
- Forma: 首屏 Hero 之后立即展示社交证明（"LA & NY's Most Exclusive Exercise Class"）
- 徕舞: 数据（3682会员/88.7%续课率）在第 5 个板块才出现，前面 4 个板块是品牌宣言
- **影响：** 用户需要滚很久才看到「这个品牌有多强」的证据

### 差距 3：Hero 信息过载
- Forma: "Now you can do Forma anywhere" 一句话
- 徕舞: 品牌名 + 主标题（两行）+ 副标题（两行）+ Scroll hint
- **影响：** 首屏信息密度高，不像高端品牌（高端品牌说一句就够了）

### 差距 4：无服务范围可视化
- Forma: 首屏下面直接展示「Studio」和「Online」两个入口
- 徕舞: 没有在任何地方直接列出「普拉提/瑜伽/塑形/体态纠正/产后修复/女性力量训练」
- **影响：** 用户不知道这个平台到底覆盖什么

### 差距 5：下半段是产品说明书
- Forma: 没有功能说明板块
- 徕舞: Ecosystem → AIReport → HowItWorks → Partner → Try → Demo，连续功能推销
- **影响：** 后半段像 SaaS 官网，不像女性成长品牌

| 优先级 | 建议 |
|:---:|------|
| P0 | Hero 简化为标题+副标题，去掉品牌名和 Scroll hint |
| P0 | 前 3 个板块内出现数据证明（会员数/续课率） |
| P1 | 服务范围在首页可被看到（不用滚到底） |
| P1 | 删除 BrandFilm 空占位 |
| P2 | 合并 Ecosystem/HowItWorks/AIReport 为一个 |
| P2 | 删除 Partner/Try/Demo 中的至少 2 个 |
