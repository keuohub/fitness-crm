# COMPETITIVE_LANDSCAPE.md

> 徕舞成长平台 · 行业竞争格局研究
> 研究时间：2026-06-04
> 8 个品牌 × 9 个维度

---

## 一、研究方法

每个品牌按以下维度分析：

1. 品牌定位
2. 首页结构
3. 用户成长机制
4. 会员留存机制
5. 社区机制
6. 内容组织方式
7. 视觉风格
8. 徕舞可借鉴点
9. 不适合借鉴点

重点不是颜色字体，是「用户为什么持续回来」。

## 二、第一组：普拉提/健身内容平台

### 2.1 The Pilates Class

**品牌定位：** 高端线上普拉提课程平台。创始人 Jacqui Kingswell 个人品牌驱动。

**首页结构：** Hero 视频 > 课程介绍 > 创始人故事 > 会员评价 > CTA 订阅

**用户成长机制：**
- 按难度分级（Beginner / Intermediate / Advanced）
- 每周新课发布，制造「回来看看」的理由
- 挑战计划（21 Day Challenge 等）

**会员留存机制：**
- 订阅制（月付/年付）
- 新课日历（知道下周有什么）
- Email 通知新课程

**社区机制：**
- Instagram 社区为主（不是内置社区）
- 用户生成内容（#thepilatesclass 标签）

**内容组织方式：**
- 视频为主
- 按身体部位、时长、难度分类
- 课程计划（Program）打包

**视觉风格：** 暖色调、自然光、创始人出镜率高

**可借鉴点：**
- 「挑战计划」概念：徕舞可以有「30天坚持计划」「100次训练里程碑」
- 新课日历 → 成长记录的「下一步预告」

**不适合借鉴点：**
- 视频内容模式（徕舞不是内容平台）
- 个人品牌驱动（徕舞是系统品牌）

### 2.2 Pilates Anytime

**品牌定位：** 全球最大的普拉提在线视频图书馆。教练驱动，非个人品牌。

**首页结构：** 搜索栏 > 课程分类 > 新课程 > 教练推荐

**用户成长机制：**
- 超过 100+ 教练，按教练跟练
- 课程难度标签系统
- 训练历史记录

**会员留存机制：**
- 内容量驱动（3400+ 课程 = 永远看不完）
- 按教练关注（Follow 教练）
- 新课程通知

**社区机制：**
- 教练-学员单向关系
- 讨论区

**内容组织方式：**
- 海量视频库
- 按教练、级别、器械、身体部位筛选
- 「我的课程」收藏

**视觉风格：** 功能性为主，设计不突出

**可借鉴点：**
- 「按教练关注」→ 徕舞的「跟随某位教练的训练记录」
- 训练历史 → 徕舞已有的 Journey 和 Evidence

**不适合借鉴点：**
- Netflix 式海量内容（徕舞不是内容平台）
- 设计感弱（缺少品牌气质）

### 2.3 Alo Moves

**品牌定位：** 高端瑜伽 + 健身 + 冥想内容平台。Alo Yoga 的生活方式品牌延伸。

**首页结构：** Hero 视频蒙太奇 > 课程分类 > 明星教练 > 系列课程 > CTA

**用户成长机制：**
- 技能路径（Skills Paths）：从新手到进阶的结构化路径
- 系列课程（Series）：多个课时组成一个学习单元
- 证书/成就系统

**会员留存机制：**
- 内容更新频繁
- 个性化推荐
- 线下活动联动（Alo Yoga 门店）

**社区机制：**
- 线上线下联动
- 教练-学员关系
- 社交媒体强运营

**内容组织方式：**
- 按风格（瑜伽/冥想/力量）
- 按教练
- 按技能路径

**视觉风格：** 高端生活方式、时尚感强

**可借鉴点：**
- 「技能路径」→ 徕舞的「成长阶段」（Day 1 → Day 365，已有 Journey）
- 系列课程 → 「训练计划」概念
- 线下联动（徕舞已有实体馆）

**不适合借鉴点：**
- 时尚感过强（与徕舞克制感冲突）
- 内容是核心产品（徕舞的核心是记录，不是课程）

## 三、第二组：训练记录/社交运动

### 2.4 Ladder

**品牌定位：** AI 驱动的力量训练 App。「像私人教练一样指导你的每一次训练。」

**首页结构：** Hero > 功能截图 > 教练团队 > 用户变化 > CTA

**用户成长机制：**
- 自适应训练计划：AI 根据你的表现调整下一节课
- 重量自动推荐
- 训练历史 + 趋势图
- Personal Record（PR）庆祝

**会员留存机制：**
- 每次训练后知道「下次练什么、多重」
- 进度可视化（Strength Score）
- 周/月总结报告
- PR 里程碑通知

**社区机制：**
- 排行榜（社区内竞争）
- 训练分享

**内容组织方式：**
- 按训练日组织（Push / Pull / Legs / Full Body）
- AI 自动安排

**视觉风格：** 暗色主题、数据驱动、科技感

**可借鉴点（高价值！）：**
- **Strength Score** → 徕舞的「成长指数」：一个数字量化会员进步
- **PR 庆祝** → 徕舞的「里程碑通知」：「恭喜！你完成了第 50 次训练」
- **自适应计划** → 徕舞的 AI 报告已有类似功能
- **训练后知道下次做什么** → 「你的下一次训练是周三」

**不适合借鉴点：**
- 暗色科技风格
- 重量/力量指标（徕舞不强调量化运动表现）

---

### 2.5 Strava

**品牌定位：** 全球最大的运动社交平台。「记录、分析、分享你的每一次运动。」

**首页结构：** Hero 截图 > 功能亮点 > 社区数据 > 订阅计划 > CTA

**用户成长机制：**
- 每次运动后自动生成数据摘要（配速、距离、海拔、卡路里）
- **Segment（路段）** 排名：同一段路谁最快
- Personal Record / 年度目标
- **每月挑战（Monthly Challenge）**：完成 X 公里获得数字徽章
- **年度总结（Year in Sport）**：像 Spotify 年度报告

**会员留存机制：**
- **Kudos（点赞）机制**：好友给你的运动点赞——社交反馈回路
- **Local Legend**：一个月内在某路段跑最多的人获得头衔
- **Fitness & Freshness 图表**：长期体能趋势
- **Relative Effort（相对努力度）**：每次训练的疲劳度评分
- **训练日志（Training Log）**：日历视图

**社区机制：**
- 关注/被关注（Follow 机制）
- Club（俱乐部）：本地跑团、品牌俱乐部
- Group Challenge（团队挑战）
- 活动照片分享
- Flyby（飞越）：看到跟你同时跑步的人

**内容组织方式：**
- Feed（动态流）= 关注的人的运动
- Profile（个人主页）= 所有运动历史
- Explore（探索）= 发现新路线

**视觉风格：** 亮橙色品牌色、地图为主、数据可视化丰富

**可借鉴点（极高价值！）：**
- **Kudos 机制** → 徕舞的「为她的坚持点赞」：教练/其他会员可以点赞
- **月度挑战** → 「30 天坚持挑战」+ 数字徽章
- **Year in Sport** → 「年度成长报告」：徕舞已有 AI 报告，可强化仪式感
- **Local Legend** → 「本月坚持之星」
- **Training Log 日历视图** → 会员训练日历（已有训练记录，加个日历视图）
- **Relative Effort** → 每次训练后的自我感受评分（1-5）

**不适合借鉴点：**
- 竞技排名（徕舞不强调竞争）
- GPS 地图（室内训练不需要）
- 公开好友系统（隐私顾虑）

## 四、第三组：习惯养成/陪伴型产品

### 2.6 Duolingo

**品牌定位：** 世界上最大的语言学习 App。「像玩游戏一样学语言。」

**首页结构：** App 内首页 = 学习树（课程路径图），Web 首页 = 功能介绍 + 数据 + CTA

**用户成长机制：**
- **学习树（Learning Path）**：可视化进阶路径，每一课是一个节点
- **XP（经验值）** + 等级系统
- **排行榜（League）**：每周升级/降级
- **宝石（Gem）**：完成课程获取虚拟货币
- **连胜（Streak）**：连续学习天数的火焰数字
- **成就徽章（Achievement Badges）**

**会员留存机制：**
- **连胜（Streak）是整个产品的核心留存机制**
  - 每天提醒：「别让你的火焰熄灭！」
  - 连胜冻结道具
  - 社交媒体炫耀连胜天数
- 每日目标设定（Casual / Regular / Serious / Insane）
- 早晚双提醒推送
- 月终总结（Monthly Report）

**社区机制：**
- 好友排行榜
- 好友连胜可见
- 送礼物（宝石）

**内容组织方式：**
- 树状路径（不可跳跃）
- 故事（Story）——情境化学习
- 复习（Practice）——系统自动安排弱项复习

**视觉风格：** 卡通风格、亮绿色、Duo 猫头鹰吉祥物

**可借鉴点（极高价值！）：**
- **连胜（Streak）是徕舞最值得借鉴的机制**
  - 「你已经连续训练 8 周了」
  - 每周训练后显示连胜火焰
  - 「别让你的记录中断」
- **学习树** → 徕舞的「成长路径」：从 Day 1 到 Day 365 的可视化路线图
- **成就徽章** → 徕舞已有的「成长勋章系统」，可加强
- **每日目标设定** → 「每周训练 2 次 / 3 次 / 5 次」
- **月终总结** → 「你这个月训练了 12 次，比上个月多了 3 次」

**不适合借鉴点：**
- 卡通/游戏化风格（与徕舞克制感冲突）
- 排行榜竞争（与徕舞「不与别人比」冲突）
- 虚拟货币系统（太复杂，不需要）

### 2.7 Headspace

**品牌定位：** 冥想与心理健康 App。「让冥想成为一种日常习惯。」

**首页结构：** Hero 动画 > 功能介绍 > 内容分类 > 数据 > CTA

**用户成长机制：**
- **基础课程（Basics Course）**：10 天入门，每天解锁一课
- **课程包（Pack）**：按主题组织（压力、睡眠、专注）
- **Run Streak**：连续冥想天数
- **总冥想分钟数**：「你已经冥想 1,247 分钟了」
- **SOS 冥想**：紧急时刻用

**会员留存机制：**
- **每日推荐（Today's Pick）**：打开 App 就看到今天的推荐冥想
- **连续天数（Streak）**：可视化你的坚持
- **睡眠内容**：每天睡前都要用，养成睡前习惯
- **统计数据**：总分钟数、总次数、平均时长
- Buddy 系统：和朋友一起冥想

**社区机制：**
- Buddy 系统（好友联动）
- 群组冥想
- 好友进度可见

**内容组织方式：**
- 按情绪/场景分类（焦虑、睡眠、专注、运动）
- 按格式分类（引导冥想、睡眠故事、音乐、练习）
- 「为你推荐」算法

**视觉风格：** 暖色、圆润插画、极简 UI

**可借鉴点（高价值！）：**
- **基础课程（Basics）** → 徕舞的「新人前 10 次训练」引导
- **Run Streak** → 与 Duolingo 同，连胜机制
- **总分钟数** → 「你已经训练了 1,247 分钟了」
- **SOS 内容** → 「今天的酸痛点缓解」：针对性内容，非紧急
- **Buddy 系统** → 「和朋友一起坚持」
- **每日推荐** → 「今天训练什么？」教练手动或 AI 推荐

**不适合借鉴点：**
- 插画风格
- 纯线上内容模式
- 心理健康术语体系

### 2.8 Calm

**品牌定位：** 睡眠、冥想与放松 App。全球下载量最高的健康类 App 之一。

**首页结构：** 每日冥想 > 睡眠故事 > 音乐 > 大师课

**用户成长机制：**
- **每日冥想（Daily Calm）**：每天更新的 10 分钟冥想
- **睡眠故事（Sleep Stories）**：名人朗读，每晚睡前听
- **Calm Masterclass**：名人授課
- 连续天数（Streak）
- 情绪检查（Daily Check-in）：今天感觉怎么样？

**会员留存机制：**
- **Daily Calm 是核心：每天都不一样，必须回来**
- **睡眠故事**：用户睡觉前打开，形成睡前仪式
- **Daily Check-in**：每天记录情绪的轻量习惯
- 统计数据

**社区机制：**
- 较弱，偏个人化体验

**内容组织方式：**
- 按场景：睡眠、冥想、音乐、大师课
- 按情绪：焦虑、感恩、专注
- 按时长：3 分钟 / 10 分钟 / 25 分钟

**视觉风格：** 自然风光、瀑布、森林、星空、极简

**可借鉴点（高价值！）：**
- **Daily Check-in** → 徕舞的「每日身体感受记录」：训练前/后一个简单问题
- **Daily Calm** → 「每日成长小记」：不是每天训练，也可以每天记录一句话
- **睡眠故事** → 徕舞的「训练故事」：教练分享一段训练心得
- **名人大师课** → 徕舞的「成长分享」
- **按时长筛选** → 不适用（训练有固定时长）

**不适合借鉴点：**
- 纯数字内容（徕舞是线上线下结合）
- 名人驱动

## 五、关键洞察总结

### 5.1 八品牌的核心留存逻辑

| 品牌 | 核心留存机制 | 一句话 |
|------|-------------|--------|
| The Pilates Class | 新课日历 | 每周有新内容 |
| Pilates Anytime | 海量内容 | 永远看不完 |
| Alo Moves | 技能路径 | 有学习目标 |
| **Ladder** | **Progress 可视化** | **看到自己变强** |
| **Strava** | **社交反馈 (Kudos)** | **被看到、被认可** |
| **Duolingo** | **连胜 (Streak)** | **不舍得断** |
| **Headspace** | **每日推荐 + 连胜** | **每天回来一下** |
| **Calm** | **Daily 内容更新** | **每天不一样** |

### 5.2 对徕舞最重要的三个借鉴

**1. Strava 的「Kudos + Local Legend」—— 被看见的渴望**
徕舞的「让坚持被看见」和 Strava 的核心理念完全一致。徕舞需要增强的是「被看见」的体验：不是自己知道自己坚持了，而是别人看见了你坚持。

**2. Duolingo 的「Streak」—— 舍不得断**
连胜数字是最简单也最好用的留存机制。徕舞可以有「连续训练周数」「连续记录天数」。

**3. Ladder 的「Progress Score」—— 一个数字总结一切**
一个「成长指数」比一堆数据更有力。比如：「你的成长指数：72（比上月 +3）」。
