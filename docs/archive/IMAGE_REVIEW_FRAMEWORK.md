# IMAGE_REVIEW_FRAMEWORK.md

> 截图分析框架
> 用途：后续所有 /view_image 截图分析必须基于此框架
> 禁止凭感觉判断，必须逐项对照

---

## 1. 字体审查标准

### 检查清单

| 检查项 | 标准 | 通过条件 |
|--------|------|----------|
| 字体族 | PingFang SC / Inter（数字） | 无宋体、无 Times、无 serif |
| 标题字重 | font-semibold | 无 font-bold、无 font-extrabold |
| 标题字距 | tracking-[-0.03em] | 不过紧、不过松 |
| 正文字重 | font-normal | 无 font-medium 正文 |
| 正文行高 | leading-[1.9] | 字与字不粘连 |
| 数字字体 | var(--font-number) | Inter/SF Pro Display |
| 字号阶梯 | H1 > H2 > H3 有明显差距 | 没有两个层级字号相同 |

### 不合格标记

- 出现 font-serif → **P0 必须修**
- 出现 font-bold 在标题 → **P1 应该修**
- 字体回退到系统默认 → **P1 应该修**
- 数字使用中文字体 → **P2 建议修**

---

## 2. 标题审查标准

### 检查清单

| 检查项 | 标准 | 通过条件 |
|--------|------|----------|
| 标题颜色 | #1D1D1F | 不含 #3E2723 标题 |
| 标题对齐 | 居中或自然左对齐 | 无奇怪偏移 |
| 标题长度 | 不超过 2 行 | 不溢出 |
| 标题号 | H1→H2→H3 层级正确 | 不用 H3 做 Section 标题 |

### 不合格标记

- 标题颜色不是 #1D1D1F → **P0**
- 标题字重不是 semibold → **P1**
- 标题超过 3 行 → **P1**

---

## 3. 留白审查标准

### 检查清单

| 检查项 | 标准 | 通过条件 |
|--------|------|----------|
| Section 上下间距 | py-32 或以上 | 两个板块不贴在一起 |
| 标题与正文间距 | mt-12 左右 | 明显呼吸空间 |
| 板块内留白 | 板块内不拥挤 | 文字不堆叠 |
| 正文栏宽 | max-w-[34em] 以内 | 视线不用大幅移动 |

### 不合格标记

- 两个板块间距小于 py-24 → **P1**
- 标题与正文间距小于 mt-8 → **P2**
- 正文栏宽超过 42em → **P1**

---

## 4. 组件审查标准

### 检查清单

| 检查项 | 标准 | 通过条件 |
|--------|------|----------|
| 卡片是否重复 | 两个组件展示相同数据 → 重复 | 不重复 |
| 卡片间距 | grid gap 8-16 | 不过密 |
| CTA 数量 | 一屏不超过 2 个 CTA | 不催促 |
| 表单是否过度 | 表单字段不超过 5 个 | 不过度索取 |

### 不合格标记

- 两个板块信息重复 → **P0**
- 一屏超过 3 个 CTA → **P1**
- 表单超过 5 个字段 → **P2**

---

## 5. 视觉层级审查标准

### Z-pattern 检查

1. 一屏打开，眼睛先看哪里？（主标题）
2. 其次看哪里？（副标题）
3. 然后呢？（品牌名）

如果视线跳来跳去 → **视觉层级混乱**

### 重量平衡检查

- 左侧重？右侧重？还是平衡？
- 上下重量分布均匀吗？
- 有没有「头重脚轻」或「头轻脚重」？

### 节奏检查

- 板块之间的视觉重量有没有强弱变化？
- 连续 5 个以上同等重量的板块 → **节奏单调**

---

## 6. AI 味检测标准

### AI 模板信号

| 信号 | 说明 |
|------|------|
| 所有板块字号完全一致 | 缺少层级节奏 |
| 所有卡片圆角相同 | 模板生成的统一风格 |
| 间距全部均等 | 没有主次关系 |
| 颜色全是 CSS 变量但无个性 | 像用了一套 UI 库 |
| CTA 按钮大小颜色完全一致 | 缺少信息层级 |

### 徕舞特有检查

- 是否出现「蜕变」「逆袭」「赋能」等禁止词
- 是否出现英文装饰（uppercase 标签过多）
- 是否出现 SaaS 模板式卡片排列

---

*此框架用于每次 /view_image 分析。逐项检查，逐项标记通过/不通过。*
