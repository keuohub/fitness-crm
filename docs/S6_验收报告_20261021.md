## 四、权限与异常

- 后台接口无 cookie：401。
- 会员 token 调教练签到：401。
- 教练 token 调后台：401。
- 课程/教室/教练/卡类型/会员卡接口均服务端鉴权。
- 无有效卡签到：422，booking 不改、attendance 不写。
- 重复签到：duplicate，不重复扣。
- 测试数据清理核对：bookings=0、sessions=0、attendance=0、member_cards=0、coaches=0、post_class_notes=0。
