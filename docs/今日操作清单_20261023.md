## 第 3 步（今天可选）：把 GitHub 仓库设为私有

1. 打开 https://github.com/keuohub/fitness-crm/settings
2. 页面最下方 **Danger Zone** → **Change repository visibility** → **Make private**
3. 确认

原因：仓库现在是公开的，历史提交里有旧的管理员口令和飞书密钥明文。
设为私有只挡住新访问，**旧口令仍要换**——第 1 步换掉 `ADMIN_PASSWORD` 就是干这个；
飞书 App Secret 建议也在飞书开放平台重置一次（重置后把新值写进本机 `.env.local` 的 `FEISHU_APP_SECRET`）。
