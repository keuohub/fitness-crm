## 0. 一句话

把「卡」从现在的固定二选一（次数卡/期限卡）改造成：

**卡种模板 = 有效期 + 额度行（可多条）+ 可约范围 + 规则 + 身份标识**

后台按「一类一类」自由搭配，会员端按同一份配置展示和校验，开卡时生成快照，模板以后怎么改都不影响已卖出的卡。

## 2. 名词对齐

- **卡种模板**：你卖的「产品」，例如：全年卡、30 次团课卡、30 课时包、私教 20 次卡、体验卡。
- **有效期**：这张卡能用多久（天数 / 固定日期段 / 长期）。
- **额度行**：这张卡能用多少次/多少课时，可以一行一行加（例如普拉提 20 次 + 大器械 10 次）。
- **可约范围**：这张卡能约哪些课种（后台配置，会员端不显示「不能约什么」）。
- **规则**：提前几天可约、多久前可取消、未到扣不扣次等，全部可调。
- **开卡快照**：会员开卡那一刻，把模板的额度、有效期、规则抄一份存到他名下。
- **身份标识**：年卡等特殊卡的徽章、身份条、预约页标记。

## 3. 卡项内容：一套卡怎么搭出来

一张卡由四部分组成，后台分开配、自由组合：

### 3.1 有效期（必填，一条）

| 方式 | 填什么 | 例子 |
|---|---|---|
| 按天数 | 数字 | 开卡起 365 天 |
| 固定日期段 | 开始日期 + 结束日期 | 2026-11-01 至 2027-10-31 |
| 长期有效 | 无 | 储值/不限时卡（本期可不做） |

### 3.2 额度行（可多条，想加几行加几行）

| 类型 | 填什么 | 扣减方式 | 例子 |
|---|---|---|---|
| 次数 | 总次数，可分配到具体课种 | 每上 1 节课扣 1 次（可对某课种设不同扣减） | 30 次；或 普拉提 20 次 + 大器械 10 次 |
| 课时 | 总课时数 | 每节课扣课时（默认 1 节 = 1 课时，可按课种设比例） | 30 课时 |
| 不限次 | 不填数量 | 有效期内按可约范围不限次数 | 全年卡 |

### 3.3 可约范围（后台配置）

- 勾选可约课种：精品普拉提 / 高定大器械 / 维密超模班 / 私教 / 瑜伽 / 以后新增的课种
- 支持「包含全部，再排除某几个」：例如年卡 = 全部课种，**排除私教**
- 会员端不出现「不能约私教」这种限制文字；只有预约失败时才提示原因

### 3.4 规则（见第 4 节，全局默认 + 单卡种覆盖）

### 3.5 五张标准卡的配置示例

| 卡 | 有效期 | 额度行 | 可约范围 | 身份标识 |
|---|---|---|---|---|
| 全年卡 | 365 天（或固定日期段） | 不限次 | 全部课种，排除私教 | 年卡徽章 + 身份条 + 预约页标识 |
| 团课 30 次卡 | 365 天 | 次数 30 | 团课类（普拉提/大器械/维密/瑜伽） | 无 |
| 30 课时包 | 180 天 | 课时 30 | 团课类，可按课种设扣减比例 | 无 |
| 私教 20 次卡 | 180 天 | 次数 20 | 仅私教 | 无 |
| 体验卡 | 30 天 | 次数 3 | 指定课种 | 无 |

## 4. 规则清单（全部不写死，后台可调）

作用域：**全局默认一套 → 单个卡种可覆盖 → 开卡时可按会员临时覆盖（写入快照）**。

| 类别 | 规则 | 默认值 | 作用域 |
|---|---|---|---|
| 预约 | 提前可约天数 | 7 天 | 全局 + 卡种 |
| 预约 | 开课前取消截止 | 2 小时 | 全局 + 卡种 |
| 预约 | 同日最多预约节数 | 2 节 | 全局 + 卡种 |
| 预约 | 未到是否扣次 | 是 | 全局 + 卡种 |
| 频次 | 每周限次 | 不启用（填了才生效） | 卡种 |
| 频次 | 单日限次 | 不启用 | 卡种 |
| 频次 | 时段限制（平日/周末/指定时间段） | 不限 | 卡种 |
| 卡务 | 开卡生效时点 | 开卡当日 | 开卡时可改 |
| 卡务 | 冻结次数 / 冻结天数 | 0 / 0（不可冻结） | 卡种 |
| 卡务 | 转让 | 不允许 | 卡种 |
| 卡务 | 退卡 | 不允许 | 卡种 |
| 扣减 | 扣减顺序 | 先到期先扣；专用卡优先 | 全局 |
| 扣减 | 课时跨课种比例 | 1 节 = 1 课时，可按课种设 2 课时 | 全局 + 课种 |
| 通知 | 逾期提醒 / 预约提醒 | 本期不做 | — |

## 5. 后台界面（两个账号全权限，不做员工角色）

1. **会员卡 → 卡种模板**
   - 卡种列表：名称、类型、价格、有效期、额度摘要、可约范围摘要、状态、引用会员卡数
   - 操作：编辑、权益行编辑、可约范围、规则覆盖、身份标识、停用/启用、复制卡种、同步到存量卡、删除（有会员卡引用时拒绝并提示改用停用）
2. **规则设置**：全局默认规则一页配完
3. **课程与教室**：保留现有，一层课种；补改名/排序/停用（已完成）
4. **会员管理**
   - 建档字段仅后台可见（姓名、手机、生日、来源、介绍人、备注等；标签只在后台）
   - 开卡：选卡种模板 → 页面带出额度/有效期/价格 → 可改其中任意一项（实收、次数、到期日）→ 生成快照
5. **排课**：现有页面沿用
6. **会员端设置**：年卡徽章样式、身份条文案（如「徕舞年卡会员」）

## 6. 会员端展示（只显示该显示的）

- **我的卡**：卡名、年卡徽章、年卡专属身份条、有效期、剩余次数（不限次显示「不限次」）、正向「可约：精品普拉提 · 大器械 · 瑜伽」
- **预约页**：年卡标识（课程卡片/头像旁）
- **不显示**：后台标签、自定义字段、限制条款、内部备注、成本与内部价格
- **只在预约失败时提示原因**（如该课种不在这张卡的可约范围）

## 7. 数据模型草案

> 现有 `card_types` / `card_type_courses` 由新模型取代；现有数据仅参考，不做迁移。

| 表 | 作用 | 关键字段 |
|---|---|---|
| `card_templates` | 卡种模板 | id, name, description, price_cents, identity_type（年卡等）, is_active, sort_order |
| `card_template_validity` | 有效期 | template_id, mode(days/date_range/forever), days, start_date, end_date |
| `card_benefits` | 额度行 | template_id, kind(count/hours/unlimited), total, sort_order |
| `card_benefit_courses` | 分课种额度 | benefit_id, course_category_id, allocated, deduct_ratio |
| `card_template_scope` | 可约范围 | template_id, course_category_id, included(0/1) |
| `card_rules` | 规则 | scope(global/template), template_id, rule_key, rule_value |
| `member_cards` | 会员卡 + 快照 | 沿用现有，增加 template_name / identity_type / badge 快照、有效期快照、规则快照 |
| `member_card_benefits` | 开卡快照与余额 | member_card_id, kind, course_category_id, total, remaining, deduct_ratio |
| `card_transactions` | 卡流水 | 沿用 |
| `class_sessions` / `bookings` / `attendance` | 课次/预约/到课 | 沿用 |

**预约校验顺序**（改造成配置驱动）：
会员 → 有效会员卡（未冻结/在有效期）→ 该课种是否在可约范围 → 对应额度行是否还有余额 → 规则校验（提前天数、同日限次、每周限次、时段限制）→ 通过

**扣卡顺序**：
到课/未到 → 匹配可约该课种的卡 → 按扣减顺序（先到期先扣、专用卡优先）选一张 → 扣对应额度行 → 写卡流水
