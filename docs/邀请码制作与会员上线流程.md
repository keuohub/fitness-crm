# 徕舞成长系统 · 每日工作流程

---

## 一、三个系统地址

| 系统 | 本地地址 | 谁用 |
|------|----------|------|
| CRM 管理后台 | `http://localhost:3001` | 你（小桥） |
| 会员 Portal | `http://localhost:3001/portal` | 会员 |
| 品牌官网 | `http://localhost:3001` | 所有人 |

- `crm.laiwufitness.com`
- `portal.laiwufitness.com`
- `www.laiwufitness.com`

## 二、每日工作流程

### 上午（约 5 分钟）

**1. 启动开发服务器**

```bash
cd /Users/qiao/Documents/徕舞工作/fitness-crm
npm run dev
```

服务器跑在 `http://localhost:3001`。

**2. 打开 CRM 首页**

浏览器打开 `http://localhost:3001`

- 看一眼顶部 5 个统计数字：总会员、活跃会员、今日反馈、本月训练、待处理
- 扫一眼会员列表，确认数据正常

**3. 飞书同步（如有新会员录入）**

打开 `http://localhost:3001/admin/sync`

- 点击「开始同步」
- 飞书表格中的新会员会被拉入 CRM
- 看同步日志确认成功条数

### 每天随时（按需）

**4. 录入训练记录**

新会员训练后：

- 打开 CRM 会员列表 → 找到该会员 → 点击进入详情
- 或在地址栏直接输入：`http://localhost:3001/members/[会员编号]`
- 点击「训练记录」→「新增训练」
- 填写：日期、类型（私教/团课/评估）、时长、备注

**5. 上传照片**

会员拍摄体态照片后：

- 进入会员详情 → 照片 → 上传
- 选择类型：身体 / 体态 / 成长
- 填写拍摄日期

**6. 查看 Usage 数据**

打开 `http://localhost:3001/admin/usage`

- 看哪些会员在使用 Portal
- 看哪些页面最受欢迎
- 切换 7/14/30 天筛选

### 新会员上线（一次性流程）

**7. 生成邀请码**

- CRM 会员列表 → 点击会员进入详情
- 在「Portal 邀请码」区域点击「生成邀请码」
- 屏幕显示 8 位码（如 `A3F2B8C1`）

**8. 把邀请码发给会员**

通过微信发给会员：

> 你的成长空间已开通。用手机 Safari 打开 portal.laiwufitness.com，输入邀请码 **A3F2B8C1** 就能看到你的训练记录和成长变化。建议添加到主屏幕，像 App 一样使用。

（本地开发时会员需要在同一网络，或上线后使用正式域名。）

## 三、会员需要做什么

### 会员只需要记住一件事

**打开手机 Safari → 输入 `portal.laiwufitness.com` → 输入邀请码**

（本地开发阶段，你在电脑上帮会员演示：`http://localhost:3001/portal/login`）

### 会员第一次使用（3 步）

| 步骤 | 操作 | 谁做 |
|------|------|------|
| 1 | 教练生成邀请码 | 你 |
| 2 | 会员打开 Portal，输入邀请码 | 会员 |
| 3 | 添加到手机主屏幕（像 App） | 会员 |

### 会员之后每次使用

从主屏幕点击「徕舞成长」图标即可进入，无需重新登录（Cookie 保持 30 天）。

### 会员可以看到什么

| 页面 | 内容 |
|------|------|
| 首页 | 名字 + 坚持天数 + 成长等级 + 每日关怀 + 三层成长环 |
| 成长页 | 旅程进度条 + 里程碑 + 勋章 + 全部成长记录 |
| 反馈页 | 月度回顾 + 坚持指数 + 教练的话 |
| 我的 | 个人资料 + 加入时间 + 等级 |
| 报告页 | 完整成长报告（评分、趋势、优势、建议） |
| 分享页 | 生成分享卡片，可截图分享 |

## 四、邀请码怎么发

### 方式一：当面告知

会员在馆里时，直接在电脑上打开会员详情页，把邀请码给对方看。

### 方式二：微信发送

复制邀请码，粘贴到微信：

> 徕舞给你开通了专属成长空间。打开 Safari 输入 **portal.laiwufitness.com**，用这个邀请码登录：**A3F2B8C1**。之后添加到手机主屏幕就能像 App 一样用。每次训练后的记录和变化，都在里面。

### 方式三：二维码（后续可做）

暂时没有生成二维码的功能，会员手动输入网址和邀请码。
