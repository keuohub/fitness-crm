# 会员批量导入（今天下午用）

后台入口：登录后打开 **会员档案 → 批量导入**（`/admin/members/import`）。只有店主或店长能导入。

## 操作顺序

1. 先在「会员卡」里建好卡种，名称和表格「卡名」一字不差。只建档、不开卡的人，卡名留空。
2. 下载页面上的 CSV 模板，或用 Excel 做同样的表头。第一行必须是表头。
3. 上传 CSV / XLSX，或把表格粘贴进输入框。
4. 点 **先预检**。失败行不会写入。把失败原因改完再预检，直到失败为 0。
5. 点 **确认写入**。下载结果里的邀请码和登录第二因子，发给会员。
6. 如果这批还没有人约课或消课，结果页可以 **撤回这批**。已经消课的卡不会被删。

同一份表可以重导。已经开通的同一张卡不会再开一张，库里已有的相伴起始日不会被覆盖。

## 列

| 列 | 必填 | 怎么填 |
|---|---|---|
| 姓名 | 是 | 最多 30 字 |
| 手机号 | 否 | 11 位大陆手机号。有手机号就按手机号认人，不会因为同名并档 |
| 性别 | 否 | 男 / 女 |
| 生日 | 否 | 2020-05-20 |
| 入会日期 | 否 | 日期 `2022-03-15`、年份 `2022`、或天数 `820` / `820天`。天数按上海今天回推，今天算第 820 天 |
| 带教导师 | 否 | 文字 |
| 备注 | 否 | 也可以把「820天」写在这里 |
| 卡名 | 否 | 必须等于后台某个启用中的卡种名称 |
| 总次数 | 次卡建议填 | 留空则用卡种默认次数 |
| 剩余次数 | 否 | 留空 = 等于总次数。记 0 次必须写 0 |
| 生效日 | 否 | 留空则用相伴起始日 |
| 到期日 | 期限卡要有 | 与「有效天数」二选一 |
| 有效天数 | 期限卡要有 | 从生效日起向后加的天数 |

不导入售价。开卡金额按 0 记，价格仍以卡种设置为准。

## 不要这样做

- 不要把两位没有手机号的同名会员放在同一张表里。
- 不要把员工姓名再建成一个没有手机号的会员。若库里出现第二个「小桥」或与教练同名的人，手机端管家会暂时不再凭姓名放行，改用手机号对应后台账号。
- 预检里出现「剩余次数和库里不一致」时，重导不会改余额。要改次数，去会员卡页面。
