# 徕舞 S6 订阅消息接入准备

> 状态：代码封装完成；**4 个真实模板 ID 未配置，尚未真实发送**。
> 不伪造模板 ID，不把未发送写成已发送。

## 一、已有条件

- `WECHAT_APPID` / `WECHAT_APPSECRET`：`.env.local` 已配置。
- 封装：`src/lib/wechat/subscribe.ts`
  - 缺 AppID/Secret、缺模板 ID、缺 openid 时返回 `skipped`，不报错、不发送。
  - 有配置时：取 access_token → 调 `message/subscribe/send`。
- 会员表有 `wechat_openid` 字段；当前多数会员未授权，需登录/授权流程补。

## 二、还缺什么

1. 微信公众平台订阅消息模板 ID：
   - 预约成功
   - 开课提醒
   - 取消通知
   - 课后记录/回音
2. 每个模板的字段 schema（字段名、长度、示例值），不能猜。
3. 用户授权：小程序端 `wx.requestSubscribeMessage`，把结果和 openid 落库。
4. 模板消息跳转页面路径。

## 三、触发场景（建议）

| 场景 | 触发点 | 模板 |
|---|---|---|
| 预约成功 | `POST /api/portal/bookings` 成功后 | 预约成功 |
| 开课提醒 | 定时任务（开课前 2–24 小时） | 开课提醒 |
| 取消成功 | `POST /api/portal/bookings/cancel` 成功后 | 取消通知 |
| 课后记录 | `POST /api/coach/notes` 成功后 | 课后记录/回音 |

## 四、接入顺序

1. 老板提供 4 个模板 ID + 字段 schema。
2. 在 `.env` 配置 `WX_TEMPLATE_*`。
3. 小程序加订阅授权按钮，保存 openid/授权结果。
4. 在触发点调用 `sendSubscribeMessage`，失败只记日志，不影响预约/签到主流程。
5. 真机测试：授权 → 预约 → 收到消息；拒绝授权 → 不发送但不报错。
6. 记录发送结果/失败原因，便于排查。

## 五、失败处理

- 缺配置/缺 openid：`skipped`，主流程不受影响。
- access_token 失败：记录错误，不重试轰炸。
- 用户拒绝授权：不发送，不重复弹窗。
- 发送失败：记录 errcode，后续可加队列重试；S6 不引入新队列。
