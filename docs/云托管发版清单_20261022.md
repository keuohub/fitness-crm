| 阶段 | 动作 | 说明 |

## 2. 构建期环境变量（✅ 已用 Lazy Init 消除依赖）

### 2.1 改造前（历史记录）

| 变量 | 读取位置 | 改造前缺失后果 |
|---|---|---|
| `DATABASE_URL` | `src/db/index.ts` **模块顶层 throw** | 构建或启动直接失败 |
| `ADMIN_PASSWORD` | `src/lib/auth/admin-session.ts` **模块顶层 throw** | 同上 |

### 2.2 改造后（当前状态）

| 模块 | 改动 | 行为 |
|---|---|---|
| `src/db/index.ts` | `neon()` / `drizzle()` 改为首次访问时创建（`db` 用 Proxy 转发，`rawSql` 仍是标签模板函数） | 导入不抛错；首次查询缺 `DATABASE_URL` 时报中文错误并提示去云托管配环境变量 |
| `src/lib/auth/admin-session.ts` | 管理员口令改为 `getAdminSecret()` 惰性读取；`verifyAdminLogin` 在口令缺失时降级为只走 DB 校验 | 导入不抛错；登录不会 500 崩溃 |

**验证证据（2026-10-22）**：

| 验证 | 结果 |
|---|---|
| 无 env 导入 `src/db/index.ts` | ✅ 不抛错 |
| 无 env 首次执行 `rawSql` | ✅ 抛明确错误：`DATABASE_URL 环境变量未设置…` |
| 无 env 导入 `admin-session.ts` | ✅ 不抛错 |
| 无 env 调用 `verifyAdminLogin` | ✅ 返回 null（不崩溃） |
| 无任何 `.env` 文件执行 `next build` | ✅ **exit 0** |
| `tsc --noEmit` | ✅ 0 错误 |

其余变量仍为惰性/兜底，缺失不会让构建失败：

| 变量 | 缺失后的行为 |
|---|---|
| `MEMBER_TOKEN_SECRET` | 回退到 `COOKIE_SIGN_KEY`，再回退到 `ADMIN_PASSWORD` |
| `COOKIE_SIGN_KEY` | 回退到 `ADMIN_PASSWORD`（**改密码会让所有会话失效**，属预期） |
| `COACH_TOKEN_SECRET` | 回退链同上 |
| `WECHAT_APPID` / `WECHAT_APPSECRET` | 订阅消息不发，其余正常 |
| `WX_TEMPLATE_*`（4 个） | 对应通知不发，其余正常 |
| `DEEPSEEK_API_KEY` | 每日反馈生成报错，不影响约课 |
| `FEISHU_*` | 与云托管无关（同步脚本在本机跑） |

> 因此：**云托管只需要配运行时环境变量，不需要构建时变量。** 若构建仍报缺变量，说明代码未更新到位，先核对部署的分支/commit。

## 3. 云托管控制台配置（逐项）

| 项 | 建议值 | 说明 |
|---|---|---|
| 服务端口 | **3001** | Dockerfile `EXPOSE 3001`，`CMD npm start -- -p 3001` 写死；服务端口必须与之一致 |
| 实例数 | 最小实例 **1**，最大 2–3 | 缩到 0 有冷启动（首个约课请求慢 1–3 秒），商用不建议全缩 |
| CPU / 内存 | 0.25 核 / 0.5G 起 | 单店量级足够；不够再升 |
| 公网访问 | 开启 | 小程序用 `wx.request` 直连默认域名，必须开 |
| 环境变量 | 见 3.1 | 运行时注入 |
| 自动扩缩容 | 开 | 白天集中约课时自动扩 |
| 日志 | 开 | 排障用 |

### 3.1 运行时环境变量（云托管 → 服务设置 → 环境变量）

| 变量 | 必填 | 值从哪来 | 备注 |
|---|---|---|---|
| `DATABASE_URL` | ✅ | Neon 连接串 | 用**轮换后**的密码 |
| `ADMIN_PASSWORD` | ✅ | 新管理员密码（强口令） | **不要再用旧值** |
| `MEMBER_TOKEN_SECRET` | ✅ | 新生成 32 字节随机串 | 缺失会让会员登录 token 用密码签名，换密码即全员掉线 |
| `COOKIE_SIGN_KEY` | 建议✅ | 独立随机串 | 让密码不再兼任签名密钥 |
| `COACH_TOKEN_SECRET` | 建议✅ | 独立随机串 | 同上 |
| `WECHAT_APPID` | 运营必填 | 小程序后台 | 订阅消息 |
| `WECHAT_APPSECRET` | 运营必填 | 小程序后台（只显示一次） | 订阅消息 |
| `WX_TEMPLATE_BOOKING_SUCCESS` 等 4 个 | 可选 | 小程序后台「订阅消息」选模板后拿 ID | 缺了只是不推送 |
| `DEEPSEEK_API_KEY` | 可选 | 轮换后的 key | 每日反馈用 |
| `ADMIN_EMAIL` | 可选 | 默认 `admin@laiwu.fitness` | 管理员登录别名 |
| `PORT` | 不需要 | — | Dockerfile 固定 3001 |

> 原则：**环境变量只放云托管控制台，不写进仓库、不写进 Dockerfile、不写进前端。**

## 4. 部署操作

1. 云托管控制台 → 服务 → 新建/更新版本 → 选择仓库分支（`release-preparation`）或上传镜像
2. 确认 Dockerfile 路径为根目录 `Dockerfile`
3. 观察构建日志：node:20-alpine 拉取 → `npm ci` → `next build`
4. 构建成功 → 发布 → 等待实例就绪
5. **不要立刻切 100% 流量**（若控制台支持版本/灰度），先本机验证冒烟
