# 微信审核前，店主要做的事

代码里已经有隐私政策、用户协议和登录前勾选。审核后台仍要店主本人填写，开发改不了。

1. 小程序后台 → 设置 → 基本设置：服务类目选健身/体育培训中已有的类目。不要选需要额外资质的医疗类目。
2. 设置 → 服务内容声明 → 用户隐私保护指引：收集信息勾选手机号、选中的照片或视频文件、相册（仅当会员上传对比照）。用途写「会员约课与身体成长记录」。隐私政策链接填发版后的 `https://你的云托管域名/legal/privacy`。
3. 用户协议链接可填 `/legal/terms` 的完整地址。
4. 准备一个审核测试会员：后台建档，记下邀请码和手机尾号或 PIN，写进审核备注。不要把真实会员的邀请码给审核员。
5. 服务器域名：request 合法域名包含云托管域名 `crm-330905-9-1509862887.sh.run.tcloudbase.com`。uploadFile 同样加上，否则对比照真机传不上去。
6. 本小程序没有支付。审核问题里回答「不涉及在线支付，会员卡在门店开通」。
7. 合并并发版后再用真机走一遍：勾选协议登录 → 约课 → 候补 → 取消 → 我的卡 → 成长记录。
