## 一、先认清：它是什么、不是什么

**是**：门店会员的「约课 + 课时账本 + 课后陪伴」工具。
- 会员：看课表、约课/取消、看我的卡（余次/剩余天数）、看课时和蜕变档案
- 教练：`/coach` 看今日课 → 名单 → 到课/未到签到（自动扣次）→ 60 秒课后记录
- 主理人：排课、开卡/续卡/调次、跟进名单、品牌文案、周期报告

**不是**：不是获客平台（小程序没有自然流量）、不收款（线下收钱，系统只记卡）、不发推送（订阅消息模板还没配）。

## 二、商用模式：靠「卡」和「课表」赚钱，系统只做承接

1. **卡 = 权益凭证**：线下收款（微信/转账/现金都行）→ 后台给会员开卡（真实卡种、次数、有效期）。
   系统不碰钱、不做退款，所有交易在线下完成，避免支付资质和退款纠纷。
2. **课表 = 可售容量**：每周排多少节、每节几个名额，决定你这周能接多少会员。课表就是产品。
3. **会员池 = 复购**：
   - 跟进名单自动抓四类人：余次≤3（该续卡）、30 天未到（该唤醒）、30 天内到期（该续费）、近 30 天生日（该关怀）
   - 「我的蜕变」课时/体态档案 = 续卡和转介绍最好的素材（会员自己愿意晒）
4. **靠什么拉新**：线下门店 + 微信群 + 会员转介绍（小程序码贴在镜子旁/前台/更衣柜）。小程序本身不带流量。

## 三、规则先定死（会员须知里写清楚，避免纠纷）

| 规则 | 现在的设置 | 建议 |
|---|---|---|
| 提前预约 | 最多提前 7 天 | 保持 |

## 四、日常怎么用（照着做就行）

### 每天（5 分钟）
| 谁 | 做什么 | 入口 |
|---|---|---|
| 前台/店长 | 看今天谁约了课、处理临时取消 | 后台 → 预约管理 |
| 教练 | 上课前看名单 → 课后点到课/未到（自动扣次）→ 写一句课后记录 | `/coach` |
| 小桥 | 回「待回便签」（会员的课后感受） | 后台 → 待回便签 |

### 每周（30 分钟，建议周日晚）
1. **排下周课**：后台 → 排课（页面会自动跳到最近有课的那一周）
2. **看跟进名单**：后台 → 跟进名单（余次低/未到/到期/生日）
3. **更新内容**：徕舞之星（本月之星）、了解徕舞文案/底图（有新照片就换）
4. **出周期报告**：后台 → 周期报告，给活跃会员生成

### 每月（1 小时）
1. 卡到期提醒 → 续卡动作（后台 → 会员卡 → 延期/续卡）
2. 数据复盘：本周预约数、到课率、未到次数、开卡数、续卡数
3. 清理：过期的卡、停用的账号、旧课次

### 会员侧怎么引导
第一次用 → 邀请码+手机尾号登录 → 看课表 → 点「预约」→ 在我的账户看「我的卡」（余次/剩余天数）。
**没卡的会员**：能看课表，点预约会提示「请联系小桥开卡」——这就是你的转化提示。

## 八、判断「跑起来了」的标准（第一个月看这 5 个数）

1. 开卡人数：5 → 目标 50+（首月）
2. 周预约数：从 0 起，稳定后看趋势
3. 到课率：到课 /（到课+未到），低于 80% 说明容量或提醒有问题
4. 未到次数：高说明需要提醒/收紧规则
5. 余次≤3 人数：这是你下个月的续卡池
