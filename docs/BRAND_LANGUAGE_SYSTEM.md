# Brand Language System — 徕舞品牌语言体系

## 品牌声音

| 维度 | 说明 |
|------|------|
| 基调 | 温暖、克制、长期主义 |
| 专业度 | 专业但不技术化 |
| 与会员关系 | 教练与陪伴者，不是系统管理员 |
| 禁止风格 | SaaS、科技公司、AI公司、管理后台 |

## 禁止词汇

以下词汇禁止出现在任何用户可见的界面中：

- AI
- GPT
- DeepSeek
- 人工智能
- 智能分析
- 智能建议
- 智能报告
- 智能引擎
- 智能评分
- 智能阶段
- 机器学习
- 算法推荐
- 自动生成
- 模型分析
- 数据驱动

## 品牌关键词

记录 / 坚持 / 觉察 / 变化 / 蜕变 / 陪伴 / 旅程 / 长期主义 / 习惯 / 阶段 / 洞察

## 允许 AI 存在的位置

- 数据库表名（`ai_feedback_reports`）
- API 路由路径（`/api/ai/*`）
- 内部代码注释（`// DeepSeek API`）
- 环境变量（`DEEPSEEK_API_KEY`）
- 文件名（`src/lib/ai/*.ts`）

这些对用户完全不可见。
