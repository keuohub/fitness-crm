> 原则：**卡和课都以你这个后台的最后一次手动保存为准**，系统不会反向覆盖。

## 一、排课（每周手动）

1. 左侧「排课」→ 默认日期是今天，点日期选择要排的那天。
2. 点「新建课次」：选课程（普拉提/大器械/维密/私教/瑜伽）、教练、教室、开始时间、容量。
3. 保存后立刻出现在会员端课表（会员只能看到未来 7 天）。
4. 教练或教室冲突：系统会给黄色提示，但**不拦截**，确认没问题照样保存。
5. 改课/删课：
   - 没有会员预约的课 → 直接删除。
   - **已经有人预约的课 → 不会真删，会变成「已取消」**（保护已有预约记录），会员端不再显示。
6. 想批量排一周：手动排 5~10 节大约 3 分钟；重复的课次可以复制日期重新建。

## 二、开卡（会员要能约课，必须先有有效卡）

1. 左侧「会员卡」→ 右上「卡类型配置」先建卡种（只需建一次）：
   - 次卡：总次数（如 10 次）、价格
   - 期限卡：有效天数（月卡 30 / 季卡 90 / 年卡 365，可自定义）
   - 每周限次：不填=不限
2. 右上「办理开卡」→ 选会员 + 选卡种 → 保存。
   - 期限卡可以指定生效日和到期日，不填就按卡种天数自动算。
3. 列表里每张卡显示：
   - 次卡：`剩余 10 / 10 次`
   - 期限卡：`剩 31 天 · 截止 2026-11-22 · 起 2026-10-23`

## 三、临时调次 / 延期（运营每天都在用，全部留痕）

| 场景 | 点哪里 | 怎么填 |
|---|---|---|
| 会员来补了 3 次（临时加） | 该卡行「调次」 | 输入 `3`，原因可写「补 3 次」 |
| 会员反映扣错了（退 1 次） | 该卡行「调次」 | 输入 `-1`，原因写「退 1 次」 |
| 次卡总数也要跟着变 | 该卡行「续卡」 | 按原逻辑加次数（会同时改总次数和剩余） |
| 期限卡要延期 | 该卡行「延期」 | 输入天数，如 `30`（从今天或原截止日中较晚的那天往后加） |
| 期限卡直接定到期日 | 该卡行「改到期」 | 输入 `2026-12-31` |
| 卡暂时不能用 | 「冻结」；恢复点「解冻」 | — |

> 调次只改「剩余次数」，不改「总次数」；每次操作都会写一条卡流水（时间、增减、原因），对账时可查。
